# Creality CFS on K2-OpenHost

`mainsail-k2openhost` contains a native dashboard panel for the Creality Filament System used by K2-OpenHost.

## Detection

The panel is shown automatically when Klipper/Kalico exposes a `box` printer object. Mainsail already subscribes to all available printer objects through Moonraker, so no extra Moonraker component or polling endpoint is required.

The first supported backend contract is:

- `box.api_version >= 1`
- `box.fluidd_widget_version >= 2`
- `box.slots` for the four CFS lanes plus the optional external slot
- `box.load_path` for buffer, encoder, printhead sensor and clog state
- `box.recovery` for blocked/retry state

The UI intentionally consumes the public `box` status object. It does not read the backend state file directly and must never depend on CFS hardware identifiers.

## Commands

The panel uses the firmware command contract documented by Jacobean's K2 firmware:

- `T<n>` selects a physical CFS slot using the full tool-change policy.
- `BOX_UNLOAD` unloads the active filament.
- `RFID_READER_READ` reads the external RFID reader cache.
- `_BOX_SET_RUNOUT_SWAP ENABLE=0|1` changes automatic matching-slot runout swapping.
- `_BOX_SET_UNLOAD_AFTER_PRINT ENABLE=0|1` changes unload-after-print.
- `_BOX_SET_RFID_INSERT_READING ENABLE=0|1` changes insertion RFID reads.
- `_BOX_SET_RFID_STARTUP_READING ENABLE=0|1` changes startup RFID reads.

The panel disables manual lane selection and unload while a print is active. Tool changes generated by the print continue to be handled by the firmware.

## Displayed state

The panel displays slot presence, loaded state, material, color, brand, name, Spoolman ID, RFID remaining percentage, CFS status, temperature/humidity when available, filament-path tracking and clog/recovery state.

## Spoolman and metadata

The backend already exposes `spoolman_id` and resolved filament metadata per slot. A future UI pass can add the complete Filament Box metadata editor and native Spoolman picker using `_BOX_SLOT_SET` / `_BOX_SLOT_CLEAR` without changing the status contract used by the dashboard panel.
